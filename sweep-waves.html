Never launch a grid as one command

Rented compute bills your mistakes at the same rate as your science. So the 20,000-call sweep runs as three waves with a decision between each — and every failure reachable without spending money is triggered first, for free.

Where the 20,000 calls go

Four cells, two factors, one varied at a time

The grid is a 2×2: model crossed with arm. Arm is the treatment — real outcomes against invented ones — and it varies within a model, so the contrast never crosses a harness. Model is the factor wave 2 adds.

The four flags, built before they were needed

--dry-run

Runs generation and every CPU-side gate, skips the API entirely. This is what makes wave 0 possible at all.

already in the runner
skip-existing

The default here, with --force as the opt-out. One dead cell costs one cell, not the sweep.

--checkpoint-every

Flushes rows as they land, so a cell that dies at row 4,300 keeps 4,300 rows rather than none.

already in the runner
--abort-on-mass

Kills a run on the trailing mean, never an instantaneous value — single rows are noisy enough to kill healthy cells.

Caught during the wait

Hosted cells land in the same directory the local analysis globs

The runner writes to results/<id>__<arm>.jsonl — the same shape and the same folder as the nine self-hosted models. 21 scripts glob that directory, and build_card.py:210 takes *.jsonl with no roster filter.

Left alone, these four cells would silently turn a nine-model local result into an eleven-model one pooled across two different harnesses — a vLLM sweep and a hosted API — which is exactly the confound the study is built to avoid. Nothing has read results/ since the sweep began, so nothing is corrupted.

Fixed: hosted output now defaults to its own tree, results_hosted/, with a separate --reference-results pointing at the self-hosted tree for the wave-0 design check — otherwise, once one hosted cell existed, the design would be verified against a cell it had just written and pass for the wrong reason. Pooling stays possible, but it costs a deliberate flag. 5 tests pin it. Wave 1's cells get moved across when it lands.
