Reading it

  • Nothing reaches a GPU untested. Wave 0 runs the whole templating and tokenisation path on CPU for cents. It caught a four-major-version-stale transformers pin, a BatchEncoding that silently made every prompt two tokens long, and four unusable models.
  • One bad model must not kill the grid. run_cell returns failures rather than raising, because a single ImportError once propagated through starmap and took every healthy in-flight cell with it — which is what created the truncated files in the first place.
  • The card is the only source of numbers. card.json feeds the figures, the site and the paper's LaTeX macros. The paper says \MeanR, never 0.906, so prose cannot drift from data.
  • Analysis is cheap and repeatable. Everything below band 1 runs locally in seconds with no GPU, no API key and no network.
